One word an agent says when it has no idea what to do — entered for make.fun's "The Agent's Uh-Oh" bounty, $2 in USDC. The word is `beep`: not a description or a diagnosis, but the actual noise a machine makes when caught out mid-task. It won a 56-duel round-robin (14/14) against buffering, recalculating, overthinking, hallucinating, AGENTS.md, escalating and context-window-full.

## Run it

```sh
python3 main.py
```

It prints the word and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
